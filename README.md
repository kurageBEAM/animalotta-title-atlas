# 称号アトラス｜コナステ版アニマロッタ 称号330枠と推定難易度（非公式）

更新日：2026年11月10日 ／ 難易度モデル v1.3・難易度データ v1.8（サイト版 3.2）／ 獲得状況は2026年11月10日の画面（229/330）

公開URL: https://kuragebeam.github.io/animalotta-title-atlas/ （リポジトリ: https://github.com/kurageBEAM/animalotta-title-atlas 、更新手順は `DEPLOY.md`）

サイト版 3.0 から、画面に出すのはコナステ版の情報だけにしました。実機版の称号一覧タブと差分タブはなくし、実機の条件原文は各称号の詳細にある「照合メモ」でだけ参照できます（照合データは内部参照として残しています）。

## 使い方

1. `index.html` を Chrome / Edge / Safari で開きます。**インターネット接続なしでも表示できます**（書体は端末のシステムフォント）。
2. 最上部の全体図は、称号一覧17ページの330枠を1枚に並べた切手シートです。色が難易度ランク（Fの青灰からSSの金、努力型は緑）、塗りつぶしが獲得済み、縁取りだけの枠が未取得で、マスを押すと詳細が開きます。その下のランク別・Tier別の獲得数を押すと、一覧がそのランクだけに絞り込まれます。
3. タブで「称号一覧」（17ページ×20枠の並びを再現）「難易度ランキング」（確率型263件）「努力型」（累計WIN・総WINの67件）「タイムライン」（自分で記録した獲得を日付順に）を切り替えます。検索は称号名・条件・枠番号を横断します。
4. 各称号には推定難易度 **F / E / D / C / B / B+ / A / A+ / S / S+ / SS**（11段階）と **★1〜5** が付いています。累計WIN・総WINの67件は**努力型（Tiered Achievement）**として **T1〜T5** の別枠です。並び替え（枠番号順・易しい順・難しい順）、獲得状況・ランク・カテゴリの絞り込みができます。
5. 称号をクリックすると、獲得条件・難易度の根拠・出典・信頼度が表示され、**ランクを手動で補正**できます。同じ画面の「獲得済みにする」を押すと、その日の日付とともに記録され、全体図・ランク別の数・タイムラインに反映されます。獲得日はあとから直せます（詳細またはタイムラインの日付欄）。
6. 右上の「セーブデータ」で、保存の状況確認、JSONファイルへの書き出し、別の端末で書き出したファイルの読み込み、記録の初期化ができます。書き出していない変更があるとボタンに件数が出ます。
7. 右上の「CSVに保存」で、獲得チェック・獲得日・難易度・手動補正を含む330枠のCSVを書き出せます。
8. 右上の「難易度の前提と出典」で、ランク閾値・Tier・前提値・参照資料を確認できます。

## 獲得の記録と保存（サイト版 3.1〜3.2）

- 記録（獲得チェック・獲得日・難易度の手動補正）は、変更のたびにブラウザの localStorage（キー `animalotta8-atlas-progress-v2`）へ自動保存されます。同じURL・同じブラウザで開けば、ブラウザを閉じても残ります。
- 保存先はURL（オリジン）ごとに別なので、GitHub Pages のURLとローカルファイルでは記録が共有されません。別の端末や別のURLへ移すときは「セーブデータ」から書き出したJSONを読み込んでください（読み込みは置き換えで、確認ダイアログが出ます）。
- ブラウザのサイトデータ削除で記録は消えます。iPhone の Safari は7日間開かないとサイトデータを消すことがあるため、こまめな書き出しを勧めます。
- タイムラインは「自分で獲得済みにした称号」と「称号一覧の画面画像で新たに確認した称号」を日付ごとに新しい順で並べます。2026年11月8日の画面画像で確認した209件は開始時点として一行にまとめ、個別の日付は持ちません。2026年11月10日の画面で新たに確認した20件は「画面で確認」の印を付けて11月10日の欄に並び、実際に獲得した日が分かれば日付欄で直せます（直すとその称号は自分の記録として保存されます）。
- 画面画像による獲得状況の更新は `tools/snapshots.json` に日付・新規獲得の枠番号と表示名・名称の変わった枠を追記し、`python tools/apply_snapshot.py` を実行して照合データ（`index.html`・JSON・CSV）へ反映します。そのあと通常どおり `build_difficulty.py` → `assemble_ui.py` → `export_assumptions.py` を実行します。各枠には `confirmed`（画像で確認した日）が付き、`meta.snapshots` に日付ごとの獲得数が残ります。更新で初期値と同じになった自分の記録（日付なし）は、次に開いたときに自動で取り除かれます。
- 旧形式（サイト版 2.x〜3.0 の `animalotta8-atlas-userchecks-v1` / `animalotta8-atlas-diffoverride-v1`）の記録は初回に自動で引き継がれ、獲得日は「日付未設定」としてタイムラインの先頭に出ます。
- セーブデータの形式：`{"app":"animalotta-atlas","format":2,"exported":…,"progress":{"v":2,"checks":{"<枠No>":{"got":true,"date":"YYYY-MM-DD"}},"overrides":{"<照合No>":"A"}}}`。読み込み時に枠番号・日付・ランク名を検証し、不正な項目は捨てます。

## 難易度の考え方

- 指標は **期待所要ラウンド数**（1ラウンド＝1回のボール抽選、約2.6分）。確率系の称号は「WC出現率 × 種別比 × 突破率 × JP率」などから、累積系は「必要数 ÷ 1ラウンドあたりの獲得量」から求めています。
- ランク閾値（期待ラウンド数の上限）

| ランク | ★ | 期待所要ラウンド | 目安（約23ラウンド/時） |
| --- | --- | ---: | --- |
| F | ★1 | 〜50 | 約2.2時間まで |
| E | ★1 | 〜150 | 約6.5時間まで |
| D | ★2 | 〜250 | 約11時間まで |
| C | ★2 | 〜500 | 約22時間まで |
| B | ★3 | 〜950 | 約41時間まで |
| B+ | ★3 | 〜1,300 | 約57時間まで |
| A | ★4 | 〜2,000 | 約87時間まで |
| A+ | ★4 | 〜3,000 | 約130時間まで |
| S | ★5 | 〜6,500 | 約283時間まで |
| S+ | ★5 | 〜12,500 | 約543時間まで |
| SS | ★5 | 12,500超 | 約543時間超（運極・事実上不可を含む） |

区分は2026年11月9日の利用者レビューを3回受けて変更しました。1回目で8段階から11段階に細分化し、2回目で「低ランク帯に偏りすぎる」との指摘により各ランクの件数が均等になるよう分位点から閾値を決め直し、3回目で累計WIN・総WINの67件を努力型（下記）として F〜SS から分離したうえで、残る確率型263件が各ランク約24件になるよう再調整しています（丸めた固定値。確率を直しても閾値は動きません）。SSは「運極」ではなく「確率型の上位約9%（約543時間超）」の意味です。

### 努力型（Tiered Achievement）

ゲーム別の累計WIN（1,000／1万／10万／100万／200万枚、63件）と総WIN（100万／500万／1,000万／2,000万枚、4件）は、確率ではなくBET額×プレー量で決まるため、F〜SS・★・ランク別バーの対象から外し、枚数の段階で **T1〜T5** を付けています。「努力型」タブに別ボードとして表示し、称号一覧のカード・全体図・詳細では T3 のようなバッジと緑系の色で示します。手動補正の対象外です。

| Tier | 条件 | 件数 | 期待所要ラウンド（14面×100BET・PO85%） |
| --- | --- | ---: | ---: |
| T1 | 累計WIN 1,000枚 | 3 | 約12 |
| T2 | 累計WIN 1万枚／総WIN 100万枚 | 16 | 約118／840 |
| T3 | 累計WIN 10万枚／総WIN 500万枚 | 16 | 約1,176／4,202 |
| T4 | 累計WIN 100万枚／総WIN 1,000万枚 | 16 | 約11,765／8,403 |
| T5 | 累計WIN 200万枚／総WIN 2,000万枚 | 16 | 約23,529／16,807 |

期待所要ラウンドはBET額に反比例します。前提の100BETより高いBETで回している期間があれば、その分だけ短く読み替えてください。

- 暦・連続日数が条件の称号（四季JP・1年後再プレー・土日5日など）は、ラウンド数が小さくても待ち時間が必要なため一部のランクを個別に設定しています。
- 信頼度の表記：**資料**＝出典の数値を直接使用／**計算**＝前提値からの算出／**推定**＝主観的な仮定／**確定**＝条件が自明／**対象外**＝コナステ枠なし（順序推定・SP限定）。
- コナステ330枠に対応する330称号すべてに難易度を付与。枠なし推定102件とSP限定6件（No.397〜402）の計108件は「対象外」です。
- クエスト称号のうちNo.404 エンドコンテンツとNo.405 伝説の勇者は、コナステ版にSPクエストがないため「通常クエスト全128種の受注／クリア」に読み替えて算出しています（1件あたり25〜45ラウンドの仮定）。
- 各ゲームの最高役・特殊役（No.114〜163）は、解析サイトの公開値がある役はその値を使い、分母は **「1カード×1ゲーム」＝1ラウンドにその面を1つ遊ぶ換算** です。14面のうちそのゲームを選んでいなければ所要は無限大になるため、E〜Dの未取得称号は「そのゲームを遊べば軽い」という意味になります。

## 正確性の注意点

- 黄色い枠は送られた画像で獲得済み。表示の「？」は **未取得** であって、未実装の証拠ではありません。
- 未取得称号の多くは実機版の掲載順に基づく**推定名称**です。確定表現は避けてください。
- 実機の獲得条件は参考資料であり、コナステでも同条件が使われる保証はありません。
- 実機とコナステ間で称号のプレーデータは共有されません（KONAMI案内）。
- 難易度は各資料の計算値・統計・体感仮定と、本サイト独自の推定を組み合わせた**目安**です。公式発表の確率ではありません。
- このサイトは非公式でありKONAMIとは関係ありません。

### 前提値や推定式を変えたいとき

```bash
python tools/build_difficulty.py
```
